# UAPD Object Detection

## Overview

UAPD Object Detection is a task-specific package derived from the UAPD release for UAV pavement distress detection.

- Task: object_detection
- Images: 3151
- Annotations: 4972
- Classes: 7 (Alligator crack, Block crack, Longitudinal crack, Oblique crack, Pothole, Repair, Transverse crack)
- Annotation format: PASCAL VOC XML bounding boxes

The source article reports 3,151 pavement images with six distress categories. The local UAPD folder also contains a rare Block crack label.
