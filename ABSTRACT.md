# Abstract

UAPD Object Detection is a curated packaging of UAPD for pavement distress detection in UAV imagery.

The source work introduces UAV-acquired pavement images and evaluates object detectors on distress localization and classification. The dataset is distributed with VOC annotations and is widely referenced in UAV road-damage research.

This package preserves publication metadata and provides generated statistics and visualization artifacts for the Large Road Damage DataLake.
